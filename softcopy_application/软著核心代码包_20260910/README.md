# 小铜人儿童针灸文化3D互动学习软件 V1.0 核心代码包

## 用途

本目录整理了能够体现软件主要功能和原创实现的前后端核心源码，可作为软件著作权源程序材料的选材基础。代码按原项目目录结构保留，便于核对文件来源和前后端调用关系。

## 核心内容

- 探案主线：关卡地图、失踪竹简案、故事任务和线索交互。
- 3D 小铜人：模型观察、穴位星点、每日探案、发现记录和百穴图鉴。
- 知识图谱：穴位、经络、身体区域、学习任务、安全提示和易混知识关联。
- 星光修补册：薄弱知识点、位置对比、修补练习、进度及奖励反馈。
- 学习闭环：任务进度、材料、徽章、奖励账本、关卡解锁及幂等发奖。
- 安全学习：儿童安全题、学习草稿和安全提示配置。
- 内容运营：穴位与探案故事的草稿、审核、发布和进度记录。

## 目录说明

- `vue3/`：Vue 3 前端核心页面、组件、接口、状态管理和任务数据。
- `springboot/`：Spring Boot 控制器、业务服务、DTO、实体、Mapper 和数据库迁移脚本。

## 申报使用说明

1. 本压缩包是核心源码归档，不是可独立运行的完整部署包；图片、3D 模型、依赖包、上传文件和运行配置未纳入。
2. 正式提交源程序鉴别材料时，应从本包中选择逻辑连续、能够体现核心功能的代码，统一添加软件名称、版本号和页码。
3. 建议优先选取 `CopperMan.vue`、`Review.vue`、`DoctorStory.vue`、`useGameState.js`、`CopperManService.java`、`KnowledgeGraphService.java` 和 `GameStateService.java`。
4. 代码中未包含数据库连接密码、令牌密钥等敏感运行配置。
5. 软件名称和版本号应与登记申请表、说明书及源程序页眉保持一致。
